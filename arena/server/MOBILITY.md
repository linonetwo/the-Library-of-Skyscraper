# Sim7 mobility authority

New sessions use simulationVersion7 / library-v5.0. Versions≤6 retain the old world-map.json and path integrator, including reset, checkpoint and replay. `mobility_types.rs` is the Rust wire; TS imports the SDK's single mobility type source. `Command::Run{actorId,viaRoomId,roomId}` and `Jump/Climb{actorId,edgeId}` share existing auth, live actor, script ownership and in-progress validation. No arbitrary coordinate/height inputs are accepted.

The canonical in-progress state is Travel.segments + segment + segmentElapsedMicros. Old path/distance/progress fields are derived compatibility views. The one500000µs budget flows across segment boundaries; durations are allocated by cumulative third-µs rounding, so exact whole-route timing is not lost to separate segment rounding. Jump lasts2000000µs; walk/run/climb speeds are750/1500/500mm per tick. Coordinates and arc sampling use signed nearest integer-mm rounding, with exact endpoints. Actors expose sampled worldHeightMilli and locomotion; lastMoveDirection remains the world tangent, or registered ladder face on vertical segments.

Ordinary movement uses only registered ordinary links. Run requires exactly two linked edges with three distinct rooms and ordinary endpoint shortest distance2. Both special edges are explicit and reversible. Walking to/from a special edge is included in its one Travel. Via rooms never commit roomId or work/healing/delivery/combat actions. High-corridor transfer/ladder/traverse topology comes from the same map registration; phase is sampled from that topology/time. No client or animation callback advances gameplay.

`travel.rs` is the compatibility/actor facade; `travel_segments.rs` owns samples and time integration, `travel_map.rs` owns versioned map adjacency, and `mobility.rs` owns domain validation/route constructors. The existing melee arrival solver clips only final safe ground tails. Preset return waits for registered safe ground and carries the same tick's unused time. Incoming enemy selection/pursuit remains on the old ground rules; sim7 damage additionally tests sampled height against the existing range. Ground-height0 keeps the old rounded ground range. Death stops at the sampled position/height, without a fall simulation.

Tests explicitly distinguish fixed coordinate/HP unit fixtures from live evidence. Mobility tests cover timing/arc/reverse ladders/mixed speeds/legal inputs/landing footprints; persistence tests cover airborne checkpoint/replay/seek/reset, old map/omitted wire extensions, safe return, and3D hit/death samples. UI, actual package/restart and art validation remain integration/release checks.
