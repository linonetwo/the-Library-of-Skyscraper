# v0.4.0 local candidate

This Linux x64 preview runs the authority, independent V8 worker and production
browser UI through `./start.sh` in the extracted package. Node.js 24 is required.
Default web/server ports are 5173/8787; configure ARENA_WEB_PORT and ARENA_PORT
as needed. The existing runtime layout and FILES.sha256 checks remain unchanged.

The v0.4 work adds schema-v2 finite state graphs and persistent decision trees over
the five official modules. Stable IDs, shared diagnostics, versioned graph state,
entry/exit memory and task-plan effects, transition cooldowns, pure scored choices
and bounded traces feed the existing TypeScript/V8 publication path. Explicit pass
continues a selector; selected hold ends it. Existing v1 projects and handwritten
TypeScript remain supported, and graph conversion is explicit and undoable.

with identical authorized world/tasks and empty graph memory; it does not advance
the match or publish. Bounded Chinese goals propose revision-based patches for
individual acceptance, rejection and undo. Unsupported phrases remain unsupported.
