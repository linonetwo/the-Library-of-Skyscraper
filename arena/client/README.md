# 竞技场客户端

React 19 + TypeScript + PixiJS 8 的本地训练与联机垂直切片。赛局状态全部来自 Rust 权威服务器，不包含模拟网络延迟、虚构资源或假事件。

## 启动

```bash
# 先在 arena/server 启动服务器（127.0.0.1:8787）
npm ci
npm run dev
# 打开 http://127.0.0.1:5173
```

`npm run build` 执行严格 TypeScript 检查与 Vite 生产构建。开发服务器代理 `/api` 和 `/ws` 到本地 Rust 服务；生产静态托管必须提供相同路径的 HTTP/WebSocket 反向代理。Vite preview 仅用于查看静态构建，并非生产服务器。

## 操作

- 首屏点击“开启训练远征”，或侧栏“联机”创建、加入共享赛局。
- 点击小队卡片或地图角色选中角色；点击六边形房间后派遣、建造哨塔或编目台。移动必须相邻，服务端会验证资源与条件。
- “规则”工作台修改预设与生命撤退阈值，点击“确认并发布规则”提交。默认小队依据规则自动行动。
- 训练局支持暂停、单步和重置；同一角色每 tick 只接受一次成功手动指令，因此暂停下连续操作应先单步。
- 纸娃娃可分别更换服装、发色、法杖。外观仅保存在当前页面 React 状态，不影响权威模拟，也不跨页面持久化。
- “日志”展示服务端最近事件；赛局结算显示真实胜者与原因。此版本不是完整回放播放器。
- 赛局凭证存储在当前浏览器标签页 `sessionStorage`，刷新可重连；不会写入 URL 或日志。联机时只分享赛局编号，不分享 token。

## 渲染与美术

`MapCanvas` 在 React 挂载周期内只创建一个 Pixi Application，状态桥更新图层，不重建 canvas。卸载释放 ResizeObserver、ticker 与 stage；隐藏页面停止渲染。WebGL 初始化失败会保留其他 UI 并显示降级原因。

可选素材：

- `public/assets/library-map.png`：手绘地图背景。
- `public/assets/doll-atlas.png` / `doll-atlas.json`：标准 Pixi spritesheet，同尺寸、同坐标的透明分层帧。
- 约定帧名：`body`、`outfit-scholar`、`outfit-warden`、`hair-ivory`、`hair-midnight`、`weapon-staff`；亦兼容 `.png` 后缀。

角色预览通过 CSS 图集裁剪，小队和地图使用相同图层顺序。缺失素材时使用明确的程序化占位角色和底色，不阻断赛局。美术资产到达后刷新页面加载。无需外部字体网络请求，优先系统 Noto/宋体。

## 已知范围

响应式界面支持桌面和窄屏；地图缩放、房间/角色拾取、资源线开关已实现。当前地图只有服务端提供的七个房间，不宣称包含完整跨层地图、迷雾、战斗特效、Steam 集成或持久回放。连接失败明确报错，指数退避自动重连；连接中断期间禁用游戏指令。
