# Mobility pose small batches

`run.mjs`, `jump.mjs`, and `climb.mjs` own separate articulation timelines and use the existing `exportPoses`/trim packer. `rig.mjs` resolves frozen body, outfit, hair, natural hand and right-hand staff registrations. No source raster is edited or generated by these scripts.

NE/SW run and jump revised small batches passed independent offline visual review and are registered in the normal main asset index, with descriptor directions limited to NE/SW. An unavailable heading keeps its own idle pose; it never borrows a reviewed direction. `candidates/ne-sw-v1` preserves the first rejected hand/staff presentation; `candidates/ne-sw` holds the accepted revision. `candidates/e-w-n-s-nw-se` contains the remaining six headings pending independent visual review. Each batch includes the entire pose contact sheet, layered atlas descriptors, contact report and eight independent outfit/hair/equipment combination loops. This is a v0.5 work in progress, not a completed 192-sequence delivery or validation of world-height contacts in the game.

Run uses a new 1.5m stride, 500ms 16-phase support/flight cycle at authority run speed 3m/s. Its arm/back/hip articulation differs from walk. Jump has eight articulation phases over the authority's 2000ms segment; root translation remains zero because world XYZ/arc height belongs to the server. The first and penultimate frames flex the hip/spine, and flight tucks then reaches the feet. No airborne XYZ is baked into sprites.

```sh
node arena/art/tools/candidates/eight-mobility/bake.mjs run NE,SW
node arena/art/tools/candidates/eight-mobility/bake.mjs jump NE,SW
node --test arena/art/tools/candidates/eight-mobility/mobility.test.mjs
```

Climb currently tests contact geometry only and is not raster-exported. It waits for independently accepted left/right grab and brace sources from the art owner. The initial hand source sample is not frozen because anatomical handedness did not pass. Do not expand directions or declare the 192-sequence matrix delivered before contact/occlusion small-batch approval.
