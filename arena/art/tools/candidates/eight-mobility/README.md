# Mobility pose small batches

`run.mjs`, `jump.mjs`, and `climb.mjs` own separate articulation timelines and use the existing `exportPoses`/trim packer. `rig.mjs` resolves frozen body, outfit, hair, natural hand and right-hand staff registrations. No source raster is edited or generated by these scripts.

NE/SW run and jump revised small batches passed independent offline visual review and are registered in the normal main asset index, with descriptor directions limited to NE/SW. An unavailable heading keeps its own idle pose; it never borrows a reviewed direction. `candidates/ne-sw-v1` preserves the first rejected hand/staff presentation; `candidates/ne-sw` holds the accepted revision. `candidates/e-w-n-s-nw-se` contains the remaining six headings pending independent visual review. Each batch includes the entire pose contact sheet, layered atlas descriptors, contact report and eight independent outfit/hair/equipment combination loops. This is a v0.5 work in progress, not a completed 192-sequence delivery or validation of world-height contacts in the game.

Run uses a new 1.5m stride, 500ms 16-phase support/flight cycle at authority run speed 3m/s. Its arm/back/hip articulation differs from walk. Jump has eight articulation phases over the authority's 2000ms segment; root translation remains zero because world XYZ/arc height belongs to the server. The first and penultimate frames flex the hip/spine, and flight tucks then reaches the feet. No airborne XYZ is baked into sprites.

```sh
node arena/art/tools/candidates/eight-mobility/bake.mjs run NE,SW
node arena/art/tools/candidates/eight-mobility/bake.mjs jump NE,SW
node --test arena/art/tools/candidates/eight-mobility/mobility.test.mjs
```

Climb uses the independently accepted NE/SW grab/brace sources in `iso-v050-mobility/climb-hands/revised/manifest.json`. Its complete finite ladder sample has 66 frames: `grip` 0–24 and `descend` 25–49 each cover the full 1.5m segment in 1500ms; `crestUp` 50–57 and `crestDown` 58–65 each cover a 0.5m transfer in 500ms. These are closed, non-looping ranges sampled once from the authority segment progress. The internal 500mm gait alternates contacts at 250mm rungs and never grips above the 1500mm top rung. Top transfer moves the leading foot and palm before releasing the other supporting hand and standing up; descent reverses this local articulation while retaining the physical ladder facing.

The climb canvas alone is 256×256 with ground pivot (128,204.8). Every projected joint and hand target receives the same (32,32) canvas margin. Root screen translation stays zero: server XYZ, height and platform movement are never baked into the sprite. The staff is stowed on the back while both independent hands grip or brace. `climb-hands.mjs` aligns each registered palm contact and wrist normal without mirroring the raster.

```sh
node arena/art/tools/candidates/eight-mobility/bake-climb.mjs NE,SW
node --test arena/art/tools/candidates/eight-mobility/{mobility,climb}.test.mjs
```

`candidates/ne-sw-climb` contains complete pose/contact sheets, per-phase sample sheets and all eight outfit/hair/equipment loops. This sample is pending independent visual review of the deep crouch, actual grip silhouettes, platform handoff and stowed staff; numerical contact tests do not establish visual acceptance. Do not expand climb directions or register this sample before that review. Public packs and the main index are maintained separately by the integration owner.
