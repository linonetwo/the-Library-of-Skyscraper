# Eight-direction enemy offline bake

Install the existing dependency with `npm ci --prefix arena/art`, then run from the checkout:

```sh
node arena/art/iso-v030-enemy/bake-eight.mjs /path/to/iso-v030-enemy /tmp/enemy-eight
```

The input preserves the accepted NE/SW action modules (`idle`, `walk`, `attack`, `hit`, `down`, each with `pose.json`). The six actual new directions come from `six/standing-rig.json` and `six/down-rig.json`; neither a mirror nor a renamed old direction supplies missing art. All attachment image paths resolve relative to their owning JSON. Each direction uses the existing shared exporter schema (joints with parent/cell/restOffset, attachments with joint/pivot/layer/zOrder, feet with joint/soleOffset). Standing directions must also contain unit `worldForward` in world XY. The six direction keys are N/E/SE/S/W/NW.

Standing registrations supply both complete three-joint legs and complete shoulder/elbow/wrist chains. Optional `attackSide` selects the striking arm (default right); optional `actionTargets.attack` supplies four explicit `wristTargets` objects using existing exporter syntax. Otherwise the actual registered arm reaches 88% of its chain length along its projected world forward; the elbow branch follows the source rest pose. This is a visual-review candidate, not motion approval.

Each action output contains copied, content-hashed attachment inputs, its standalone `pose.json`, and `baked/` atlases, budget descriptor, contact sheet, skeleton/debug pages and GIF generated by `arena/art/tools/pose-export.mjs`. `source-registration.json` records input attachment paths and full SHA256 values. The output can be rebuilt without the original input tree by invoking the shared exporter on its individual pose files. Large original generated sheets remain in the source producer's directory.

The shared world-chain solver owns leg projection. Enemy registration is 1.35 world height, .265/.255 leg segments, hip .54, ankle .10, track .16; the walk has 16 × 45ms phases and 1.08 world stride. Idle is 4 × 400ms. Ordinary cells use 192px with pivot (96,172.8), down uses 256px with pivot (128,204.8), both scale 1. Original NE/SW action poses are retained, with idle timing normalized to 400ms. Down retains the producer's four real painted poses and ground-support metadata.

This script does not edit runtime assets, the client, service, source rig, or player art. Missing actual directions fail before that action exports. Review the real generated `baked/contact-sheet.png` and continuous playback before accepting a candidate.
