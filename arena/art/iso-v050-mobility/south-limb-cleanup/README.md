# S 向 run / jump 大腿净源

两张原附件来自已发布八向基础站姿裁图，外侧夹入了原人物垂手的肤色像素。短裤和整条腿保持原位，仅将这段旧手及微弱边缘 alpha 置零；不重绘、不补色、不裁尺寸。左右按角色解剖方向。

`comparison.png` 每行从左至右：原图、实际删除像素（红色）、净源。上行是左腿，下行是右腿。`manifest.json` 记录源版本、原／新 PNG SHA-256、髋枢轴和精确遮罩。`node register.mjs` 使用现有 `arena/art` 的 sharp 依赖及本仓库 git 对象复建。

只给 S 向疾跑和跳跃替换各自的大腿 `image`；不要覆盖既有基础附件、其他七向或攀梯素材。袖口缺掌是另一处消费端拆层问题，不由这两张图修复。
